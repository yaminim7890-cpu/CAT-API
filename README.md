# Random Cat Image Fetcher

A Node.js application that uses The Cat API to fetch a random cat image and display the returned JSON data in the console. The application displays the cat ID, image URL, width, and height.

 # Features

- Fetches a random cat image
- Displays cat ID
- Displays image URL
- Displays image width and height
- Opens the image URL in a browser
- Handles API errors using try-catch

# Technologies Used

- Node.js
- JavaScript
- The Cat API
- Fetch API
- Async/Await
